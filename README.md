# تطبيق ميقات (أندرويد)

## بناء ملف APK بدون Android Studio
1. أنشئ حساب مجاني على github.com ثم مستودعًا جديدًا (New repository).
2. ارفع كل محتويات هذا المجلد (Add file ← Upload files). لو لم يُرفع مجلد `.github` فأنشئ الملف يدويًا:
   Add file ← Create new file ← اكتب الاسم `.github/workflows/build-apk.yml` والصق محتوى الملف.
3. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**. انتظر نحو ٥–١٠ دقائق.
4. من صفحة التشغيل نزّل الملف **miqat-apk** (zip)، فك الضغط، وانقل `app-debug.apk` إلى الهاتف وثبّته
   (فعّل "السماح بالتثبيت من مصادر غير معروفة"). لا يحتاج Google Play.

## صوت الأذان
- بدون ملف، يُولَّد صوت تنبيه بسيط تلقائيًا.
- لاستخدام أذان حقيقي: ضع ملفًا باسم `adhan.mp3` داخل مجلد `resources` (يفضل ٣٠ ثانية أو أقل)، وتأكد أن لديك حق استخدام التسجيل.

## ملاحظات
- التطبيق يعمل بالكامل بدون إنترنت: المواقيت تُحسب داخل الجهاز. الإنترنت يُستخدم فقط لتحميل الخط من Google (وله بديل من خط الجهاز).
- في إعدادات الهاتف اجعل التطبيق "بدون قيود بطارية" (Unrestricted)، وفعّل التنبيهات والمنبهات الدقيقة، وإلا قد تتأخر بعض الهواتف (شاومي/سامسونج/أوبو) في الإشعارات.
- يُجدوِل التطبيق ١٤ يومًا قادمة عند كل فتح، فافتحه مرة كل أسبوعين على الأقل.
- iPhone: يحتاج جهاز Mac وحساب Apple، وهذا المشروع مجهز لأندرويد فقط.
